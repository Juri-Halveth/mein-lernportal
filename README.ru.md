# Mein Lernportal

**Краткий путеводитель по проекту · EN / RU**

Свободно доступный статический учебный портал с 702 уроками в 13 тематических мирах в проверенной редакции источника. Каталог включает викторины, задания по программированию, визуализации, поиск и локальный прогресс браузера с экспортом и импортом.

Bash Big Bang связывает практическое обучение Git Bash с более широкой коллекцией тем. Lernstudio — связанная, но отдельно поддерживаемая платформа. Исходная README и уведомления определяют содержимое, ссылки на источники и применимые права.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.
