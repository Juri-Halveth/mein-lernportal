Was direkt passiert

Beim Öffnen lädt dein Browser die statischen Dateien des Portals von GitHub Pages. Danach kannst du Themen durchsuchen, Lektionen öffnen, Übungen bearbeiten und deinen Fortschritt lokal markieren. Python-Aufgaben laden erst auf deinen ausdrücklichen Start hin den separat lizenzierten Pyodide-Laufzeitcode von jsDelivr.

Was nicht im Hintergrund passiert

Das Portal enthält keine Anzeigen, Ad-Netzwerke, Analysepixel, Marketing-Cookies oder Fingerprinting. Es startet keine Kampagne und veröffentlicht keine Botschaft im Namen eines Besuchers.

Zeichen für Menschen

Wissen kann Menschen verbinden. Deshalb darf das Portal offen sagen: Finde Fähigkeiten, Fragen und andere Menschen über gemeinsame Interessen. Dieser Satz ist eine redaktionelle Einladung des Portals. Er ist keine persönliche Nachricht einer unbekannten Person und löst keine verdeckte Aktion aus.

Mitmachen

Fehler, bessere Erklärungen und neue Ideen können öffentlich über GitHub vorgeschlagen werden. Eine Änderung erscheint erst, wenn sie als nachvollziehbarer Commit in diesem Projekt landet.
